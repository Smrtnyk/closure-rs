## Es6RewriteDestructuringTest (post-call assertions, gate 0.2 (a))

Methods of `com.google.javascript.jscomp.Es6RewriteDestructuringTest` whose assertions after the hooked `test(...)` call inspect compiler-internal state of the output AST (`getLastCompiler().getJsRoot()`): the `Color` objects attached to nodes, or a `Node` boolean property. No `postCall` key, test field or postcondition records them, and the AST comparison (`Node.isEquivalentTo`) ignores them. The records still replay (input, expected output, diagnostics) but are excluded from gate (a) counting under D-015; the checks below are ported as Rust unit tests next to Es6RewriteDestructuring.

- Es6RewriteDestructuringTest#testArrayDestructuringRest_getsCorrectTypes: in the rewrite of `const [a, ...rest] = iterableVar` (iterableVar `!Iterable<number>`), `$jscomp.arrayFromIterator` has color TOP_FUNCTION, its CALL and the NAME `rest` have the registry's ARRAY color
- Es6RewriteDestructuringTest#testArrayDestructuring_getsCorrectTypes: in the rewrite of an array pattern over `!Iterable<number>`, `$jscomp$destructuring$var0` has the registry's ITERATOR color, `a` and `$jscomp$destructuring$var0.next().value` have NUMBER, and `$jscomp$destructuring$var0.next()` has UNKNOWN
- Es6RewriteDestructuringTest#testObjectDestructuringComputedPropWithDefault_getsCorrectTypes: in the rewrite of `const {['a']: a = 4} = obj` (obj `!Object<string, number>`), `a` has NUMBER, the initializer of `$jscomp$destructuring$var0` has TOP_OBJECT and the NAME `$jscomp$destructuring$var0` has that same color
- Es6RewriteDestructuringTest#testObjectDestructuringDefaultValue_getsCorrectTypes: in the rewrite of an object pattern with a default value, `a` has NUMBER and `$jscomp$destructuring$var0` has the same color as `obj`
- Es6RewriteDestructuringTest#testObjectDestructuringRest_typesRestAsObject: in the rewrite of `const {...rest} = obj`, `$jscomp$destructuring$var0` and `$jscomp$destructuring$var1` have the color of `obj`, and `rest` has TOP_OBJECT
- Es6RewriteDestructuringTest#testObjectDestructuring_getsCorrectTypes: in the rewrite of a simple object pattern, `a` has NUMBER and `$jscomp$destructuring$var0` has the same color as `obj`
- Es6RewriteDestructuringTest#testSimpleDestructuring_constAnnotationAdded: rewriting `function foo(...{length}) {}` gives a NAME `$jscomp$destructuring$var1` (second statement of the function body) with the IS_CONSTANT_NAME property set
