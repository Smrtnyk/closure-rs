## RuntimeLibraryTypedAstInjectionTest (post-call assertions, gate 0.2 (a))

`com.google.javascript.jscomp.RuntimeLibraryTypedAstInjectionTest` tests the harness's runtime library injection from TypedASTs (`ensureLibraryInjected`, recorded in `harness.fields.librariesToInject`); its `getProcessor` is the no-op lambda `(externs, root) -> {}`. Every method asserts, after the hooked call, on Java objects of the final AST (`getLastCompiler().getRoot()`): the `Color` objects of NAME nodes (identity with `isSameInstanceAs`, or null), their source file names and the absence of CAST nodes. The records' post-call snapshot carries only `postCall.compiler.accessorSummary`, `postCall.compiler.moduleMetadataByPath` and, for the type-checked record, `postCall.compiler.typeMismatchesError`; none of them, no test field and no postcondition records node colors or source files, and the AST comparison ignores both. Because the processor is a no-op, the class is vacuous under the whole-processor no-op check, so without these post-call checks its records prove nothing about a pass; they are excluded from gate (a) counting (D-015) and the checks below are ported as Rust unit tests of the TypedAST runtime library injection (category `color`).

- RuntimeLibraryTypedAstInjectionTest#testInjection_carriesReconciledTypeInformation: with type checking and `util/owns` injected, the final AST has exactly two NAME `Object` nodes, the first from a source file containing `util/owns` and the second from `testcode`, and both carry the same non-null `Color` instance (test lines 47-75, record index 2)
- RuntimeLibraryTypedAstInjectionTest#testInjection_excludesTypeInformation_ifTypecheckingHasNotRun: without type checking and with `util/owns` injected, the two NAME `Object` nodes come from `util/owns` and `testcode` respectively and both have a null color (test lines 78-105, record index 1)
- RuntimeLibraryTypedAstInjectionTest#testInjection_doesntCrashOnLibrariesWithCasts_ifTypecheckingHasNotRun: without type checking and with `util/global` injected, the final AST has exactly four NAME `globalThis` nodes, the first from `util/global` and the fourth from `testcode`, both with a null color, and contains no CAST node (test lines 108-133, record index 0)
