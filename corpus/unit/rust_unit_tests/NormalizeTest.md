## NormalizeTest (post-call assertions, gate 0.2 (a))

Methods of `com.google.javascript.jscomp.NormalizeTest` that, after the hooked `test`/`testSame` call, walk `getLastCompiler().getRoot()` and assert which NAME/STRING_KEY nodes carry `Node.IS_CONSTANT_NAME` (Normalize's constant-name annotation, propagated by MakeDeclaredNamesUnique and PropagateConstantAnnotationsOverVars). Node properties are not part of the AST comparison and no `postCall` key records them, so each method's single record is excluded from gate (a) counting under D-015 (a harness request asks for a neutral `postCall` key listing constant-name nodes, which would make them captured). The checks are ported as Rust unit tests next to Normalize.
