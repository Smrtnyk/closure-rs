## RemoveUnusedCodeTest (post-call assertions, gate 0.2 (a))

Methods of `com.google.javascript.jscomp.RemoveUnusedCodeTest` that the static post-call scan flags (the scan treats hook-reaching helpers as hooked calls). In each of them the only statements after a hooked call that the scan takes for assertions are calls of the test-local builder `PolyfillRemovalTester.addPolyfill`, whose `checkArgument(!polyfills.contains(polyfill), "duplicate polyfill added: >%s<", polyfill)` (RemoveUnusedCodeTest.java:2448-2454) guards the tester's own `LinkedHashSet<String> polyfills` against duplicates before that set is joined into the next hooked call's input. The guard reads no compiler state; every hooked call is a record whose input, expected output and diagnostics replay. The records' `postCall` holds `compiler.accessorSummary` and `compiler.externProperties` and no pass key, none of which is the test-local list. The records are excluded from gate (a) counting under D-015; the guard is test-construction logic, kept here so that a Rust port of the polyfill-removal tests builds its inputs with the same no-duplicate rule.

- RemoveUnusedCodeTest#testRemoveUnusedPolyfills_guardedGlobals: `tester.addPolyfill(promisePolyfill)` between hooked calls must not add a polyfill string the tester already holds (test-local input construction; 3 records)
- RemoveUnusedCodeTest#testRemoveUnusedPolyfills_prototypeProperty_untyped: `tester.addPolyfill(stringIncludesPolyfill).addPolyfill(arrayIncludesPolyfill)` between hooked calls must not add a polyfill string the tester already holds (test-local input construction; 15 records)
- RemoveUnusedCodeTest#testRemoveUnusedPolyfills_staticProperty_untyped: `tester.addPolyfill(setDotFromPolyfill)` between hooked calls must not add a polyfill string the tester already holds (test-local input construction; 7 records)
